# Security policy

## Supported versions

I fix security problems on `main`. The demo has no releases, so pull the latest
`main` before checking whether a problem still occurs. Report a vulnerability in
one of the gems to that gem's repository.

## Report a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/cosgroveb/ruby-osc7501-demo/security/advisories/new).
Do not disclose vulnerabilities in public issues or pull requests.

Include the commit you ran, your Ruby version, steps that reproduce the problem,
and the impact. Include terminal and tmux versions when relevant. Remove
credentials and unrelated private data from examples.

I review reports and coordinate a fix and public disclosure with the reporter.
Please keep details private while we work out disclosure. I cannot guarantee
response or fix deadlines.

For ordinary bugs, use the [issue tracker](https://github.com/cosgroveb/ruby-osc7501-demo/issues).
